# 负压电机 AI8051U 无刷电调固件

这是负压电机使用的 AI8051U 无感六步换相电调工程，使用 Keil C251 构建。它与同级 `../drive-esc-ai8051u/` 的行进电调是两套独立固件，不能混刷。

## 构建

1. 安装 Keil C251 与工程依赖的逐飞库。
2. 打开 `project/` 下的 `.uvproj` 工程文件。
3. 确认目标是负压电调板，在不接负压电机或使用受限电源的条件下完成首次烧录与验证。

## 关键配置

主要控制参数在 `bldc/bldc_config.h`。负压电机的 PWM 量程、最大占空比、保护阈值与响应限制应按负压系统单独设置，不能复制行进电机参数。
