# 文档图片

本目录用于 README、使用说明和发布页中的展示图片，不存放原理图、PCB 生产文件或 CAD 源文件。

建议按以下名称放置图片：

| 文件名 | 内容 |
| --- | --- |
| `vehicle-overview.jpg` | 完整车辆正面或俯视图 |
| `vehicle-undercarriage.jpg` | 底盘、轮组与负压结构 |
| `electronics-overview.jpg` | 主控、行进电调、负压电调与接线概览 |
| `pathcapture-overview.png` | PathCapture 上位机界面 |
| `node-planner-overview.png` | 节点路径规划器界面 |
| `track-run.jpg` | 赛道运行或路径复现画面 |

图片应避免展示个人信息、串口号、账号、订单或无关的电脑桌面内容。优先使用清晰的 PNG/JPEG，并保持单张图片在合理体积内。
