# 纯惯导硬件

> 本文记录本车硬件架构的设计经验。它不是可直接照抄的原理图或 BOM；供电、接地、烧录、散热和保护设计应以仓库当前硬件资料及实物验证为准。

## 电调架构

行进端采用逐飞 AI8051 电调方案，并改为一拖三结构；软件侧已做针对本车的调整。电调使用与构建说明见仓库中独立发布的行进与负压电调工程。

AI8051 的烧录接口必须预留。三块 8051 的反复烧录会直接影响维护效率；主控烧录口的串口可复用为高速无线串口，但使用前需确认电平、供电和串口复用状态。

## 双 IMU、减振与屏蔽

车辆采用双 IMU，通过洋白铜多点接地屏蔽电磁干扰，并帮助均匀分摊热量。

双 IMU 的价值主要在振动和零漂工况：当减振结构已能抑制主要振动时，两颗 IMU 的角度误差有机会呈相反趋势，平均后可让主体角度变化更缓慢。它不是无条件增益，必须以两路原始数据和融合结果验证。

洋白铜在本项目中承担多项作用：电磁屏蔽、散热均热、保护 IMU、粘接减振材料和增加适量配重。稳定的安装工况本身是惯导工程的重要部分。

## 编码器连接与磁屏蔽

编码器通过 FPC 连接到主板，体积小且实测数据稳定。项目曾设计 3D 打印屏蔽罩，但当前安装条件下未继续使用。

需要区分两类屏蔽：

- 良好接地的铝合金或铜对高频电磁场和电场屏蔽有帮助。
- 对强磁电机可能带来的低频磁场干扰，通常需要高磁导率材料，例如坡莫合金；普通接地铝或铜对此效果有限。

可行的机械方案是使用 3D 打印支架，使磁铁位于支架中，再将坡莫合金贴合在支架上形成磁屏蔽结构。是否需要实施应由编码器实际误码、角度稳定性和电机距离测试决定。

## 后续方向

后续硬件目标是继续提升供电、传感器和电调的稳定性，并评估 FOC 驱动方案。FOC 不只是替换算法，还涉及电流采样、PWM/ADC 同步、保护、位置反馈与整套驱动板设计，应作为独立硬件迭代完成验证。
