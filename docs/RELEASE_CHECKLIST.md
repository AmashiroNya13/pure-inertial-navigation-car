# 公开发布检查清单

- [ ] 删除或确认不包含本地绝对路径、串口号、个人信息和赛场数据。
- [ ] 不提交 `archive/`、`venv/`、缓存、日志、二进制和构建产物。
- [ ] 检查主控固件、电调、SDK 和逐飞代码的原始许可证与再分发条件。
- [ ] 确认硬件和机械文件的版本、单位、层叠和生产注意事项。
- [ ] 架空实车验证急停、最低速度、串口连接、路径上传与停止命令。
- [ ] 在一台未配置开发环境的电脑上按 README 从零启动 PathCapture。
- [ ] 选择仓库地址后初始化 Git，并在首次提交前执行 `git status --ignored`。
