# 上游来源

## MotorCycle

- 上游仓库：[XCELINE / MotorCycle](https://gitee.com/xceline566/motorcycle)
- 作者：XCELINE
- 本地核对的上游版本：`7d0cf85`
- 上游许可证：GNU GPL-3.0

本项目的 TC2xx 主控工程以该项目的早期工程结构和部分基础实现为起点，后续已对路径复现、车辆控制、速度和姿态策略、串口协议、路径工具与上位机进行了大量修改和扩展。

本仓库不是上游的官方 fork，也不应将后续新增内容归因给上游作者。与此同时，基于上游 GPL-3.0 代码的部分仍须遵守其适用的许可证义务；逐飞、Infineon 等其他第三方内容继续以各自原始许可证为准。
