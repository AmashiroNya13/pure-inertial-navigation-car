# AI8051U 无刷电调固件

这是 AI8051U 的无感六步换相电调工程，使用 Keil C251 构建。

## 构建

1. 安装 Keil C251 与工程依赖的逐飞库。
2. 打开 `project/` 下的 `.uvproj` 工程文件。
3. 在不接动力电机或使用受限电源的条件下完成首次烧录与验证。

## 关键配置

主要控制参数在 `bldc/bldc_config.h`，包括 PWM 范围、最小/最大占空比、开环换相次数、闭环等待次数、速度增量限制和电机进角。

电调输入与主控 PWM 的协议、频率和量程必须一致。修改前先记录原始值；任何更改都应在架空状态验证低油门启动、停转、欠压保护和失控保护。
